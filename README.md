# Морской бой — перископ

Браузерная игра по мотивам советского игрового автомата «Морской бой»: смотрите
в перископ, берите упреждение и топите корабли с наибольшим суммарным тоннажем
за 10 торпед (за 10 попаданий из 10 — ещё 3 призовые).

- Техническое задание — [docs/TZ.md](docs/TZ.md)
- Решения по неясностям ТЗ — [docs/DECISIONS.md](docs/DECISIONS.md)

## Запуск

Нужен [Node.js](https://nodejs.org) версии 20 или новее. Сторонних библиотек нет.

```bash
npm start
```

Затем откройте в браузере http://localhost:8090. Остановить сервер — `Ctrl+C`.

Если Windows PowerShell отвечает «running scripts is disabled on this system»,
запускайте `npm.cmd start` или работайте в PowerShell 7.

## Управление

| Действие | Как |
|---|---|
| Поворот перископа | Мышь (после щелчка по перископу) или стрелки ← → |
| Пуск торпеды | Пробел или левая кнопка мыши |
| Отпустить мышь | Esc |

## Проверка

```bash
npm test
```

Автотесты проверяют игровую логику (`tests/logic.test.js`).

**Режим отладки:** откройте http://localhost:8090/?debug. Тогда состояние игры
доступно в консоли браузера (F12) как `periscope.game`.

## Как устроено

| Файл | Что делает |
|---|---|
| `src/config.js` | Все настройки: скорости, число кораблей, размер моря, обзор, эффекты |
| `src/logic.js` | Игровая логика без графики и звука: движение, попадания, счёт, бонус, конец партии |
| `src/render.js` | Рисует вид через перископ |
| `src/audio.js` | Синтезирует звуки пуска и взрыва |
| `src/input.js` | Мышь и клавиатура |
| `src/hud.js` | Показатели, сообщения, итоговый экран |
| `src/main.js` | Связывает всё в игровой цикл |
| `server.js` | Мини-сервер для локального запуска |

## Критерии приёмки (ТЗ §12) — чем проверяются

| # | Критерий | Автотест | Вручную |
|---|---|:---:|:---:|
| 1 | Перископ плавно вращается на 360° мышью и стрелками | ✔ (переход 359°→0°) | ✔ |
| 2 | Пробел и левая кнопка — одна торпеда на нажатие | ✔ | ✔ |
| 3 | Корабли разными курсами и скоростями | ✔ | ✔ |
| 4 | 3 / 5 / 8 иллюминаторов, тоннаж 1 000 / 3 000 / 6 000 т | ✔ | ✔ |
| 5 | Нужно упреждение | ✔ | ✔ |
| 6 | Поворот после пуска не меняет курс торпеды | ✔ | ✔ |
| 7 | Несколько торпед одновременно | ✔ | ✔ |
| 8 | Попадание: звук, вспышка, пожар, потопление | ✔ (событие) | ✔ |
| 9 | Потопленный корабль засчитывается один раз | ✔ | |
| 10 | Начальный боезапас 10 | ✔ | ✔ |
| 11 | 10 попаданий из 10 → ровно 3 призовые | ✔ | ?debug |
| 12 | Любой первоначальный промах исключает бонус | ✔ | |
| 13 | Партия не кончается, пока торпеды в пути | ✔ | ✔ |
| 14 | Итоговый тоннаж = сумма тоннажей | ✔ | ✔ |
| 15 | Новая партия полностью сброшена | ✔ | ✔ |
