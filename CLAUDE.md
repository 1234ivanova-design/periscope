# CLAUDE.md — «Морской бой — перископ»

Учебный проект (модуль 1 курса). Заказчик — Сергей. ТЗ: `docs/TZ.md` — не менять
без заказчика. Решения по неясностям ТЗ: `docs/DECISIONS.md` — дополнять при каждом
новом решении.

## Команды
- `npm start` — локальный сервер, http://localhost:8090 (`?debug` — состояние в `window.periscope.game`)
- `npm test` — автотесты логики (`node:test`, без зависимостей)

## Правила
- `src/logic.js` — только логика: без DOM, canvas и звука. Всё, что видно или
  слышно, логика сообщает через `game.events`.
- Все числовые настройки — только в `src/config.js`.
- Изменение логики — вместе с тестом в `tests/logic.test.js`.
- Без внешних библиотек и сборщиков. Интерфейс и комментарии — на русском.
- Новые механики (уровни, магазин, улучшения, сеть) — только по согласованию (ТЗ §11).
